# v1.6.3 与 v1.5.0 功能对照

对照基线是 GitHub 正式发布的 v1.5.0 ZIP，下载后核对了发布者提供的 SHA-256。v1.6.3 的完整 ZIP 用于首次安装和修复，独立 EXE 用于升级已有安装。[v1.5.0 正式包](https://github.com/st-cx/WYU-ESurfing-Auto-Login/releases/tag/v1.5.0) · [v1.6.3 正式包](https://github.com/st-cx/WYU-ESurfing-Auto-Login/releases/tag/v1.6.3)

| v1.5.0 已有能力 | v1.6.3 的行为和检查 |
|---|---|
| 安装、登录自启、校准、卸载 | 保留原 BAT 和校准工具。用原版 ZIP 初始化临时安装，再从新版入口升级，检查原配置、网卡和校准数据。另测了全新安装、任务缺失后修复及卸载。 |
| 宿舍断网监测、离校静默 | 保留 HTTP 状态码及正文检测、失败阈值和离校复查间隔。唤醒时先区分网卡未就绪、校园网和校外网络。 |
| 官方客户端登录、后台和前台点击、网卡修复 | 识别到稳定的登录按钮才提交，保留启动等待、客户端重启、网卡修复冷却和恢复通知。持续错误页和等待账号、DHCP、校外网络分别处理。 |
| Clash for Windows、Clash Verge Rev、系统代理、PAC 和 TUN | 覆盖 CFW、Verge 服务和普通模式、过期配置与自定义控制器、Meta 网卡、暂停及还原。代理单独故障时保持校园直连，认证过程中主动更改的代理设置也会保留。 |
| 认证互斥和中断恢复 | 共享认证锁，读取已有恢复记录。回归覆盖并发、恢复失败后的重试和还原后的 HTTP 验证。 |
| 手动排障和旧配置 | 保留 `-Check`、`-RecoverOnce`、`-RestoreNetwork`、命令文件、日志、截图及原校准参数。校外执行单轮恢复仍返回 2。旧配置缺失的新字段有默认值。 |

## 新版新增能力

- **托盘和账号窗口**　短状态一行可读，长提示自动换行，超长内容可以滚动至末行。手动打开后可持续查看。在 Windows 原生窗口检查了 100%、125%、150%、200% 四档缩放和 28 组布局。
- **账号选择**　支持本机设置默认账号、十秒内改选备用账号及同次 Windows 登录内沿用选择。识别测试覆盖全部十个数字和仅一位不同的账号。
- **升级保护**　备份程序及计划任务，并以新版进程和托盘的本次启动回执确认升级。回归覆盖启动失败后的回滚、可选脚本的识别和保留、缺失任务修复以及重复升级。
- **独立更新包**　EXE 和同目录 CMD 均支持 `--check`。完整安装包可放在含中文或空格的目录。仅有源码时，CMD 会先调用 Windows 自带的 .NET Framework 编译器构建更新程序。

## 如何复核

解压完整 ZIP 后，从其根目录运行所用 PowerShell 对应的命令。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run-all.ps1
pwsh -NoProfile -File tests\run-all.ps1
.\CampusNet-Update-1.6.3.cmd --check
```

发布检查会从原版 ZIP 建立临时安装，在临时用户目录中模拟任务计划程序、设备状态和新版启动回执。网络回归使用本地 HTTP 服务、命名管道和模拟代理。发布附件的 SHA-256 记录在同一 Release 的 `SHA256SUMS.txt`。

本次未在真实断网下重新进行冷启动或锁屏登录。Windows 用户尚未登录时，交互式任务要等用户登录后启动。已登录后锁屏时，后台认证取决于天翼能否提供可识别的窗口画面。其他学校的客户端界面和校园网特征需在对应环境确认。
